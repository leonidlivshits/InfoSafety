# ADR-002: Жёсткая валидация ввода с Pydantic и бизнес-проверками

## Статус
Принято

## Контекст
API принимает payload для создания/обновления media. Бизнес-правила должны соблюдаться на границе API и в сервисном слое.

## Решение
- Использовать Pydantic для синтаксической валидации.
- Применять совместимые с Pydantic v2 валидаторы (`@field_validator`/`@model_validator`) или эквивалент для бизнес-правил.
- Добавить unit/integration тесты для некорректных входов.

## Последствия
- Плюсы:
  - Предотвращает tampering и некорректные состояния (NFR-05).
  - Упрощает контрактную проверку; тесты покрывают границы.
- Минусы:
  - Требует поддержки валидаторов при изменении правил.

## Связи
- NFR: NFR-02, NFR-05
- STRIDE: F2/F4 (tampering, injection)
- Тест: `tests/test_secure_coding.py::test_validation_rejects_rating_if_not_done`
